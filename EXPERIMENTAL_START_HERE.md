# Experimental AMD architecture builders

**Source build only. This branch is experimental and does not include precompiled native modules for other GPUs.**

For the tested RX 9070 XT/gfx1201 package, return to [main](https://github.com/BoomerCyb/ComfyUI-LODTailor-Bake-Forger-AMD/tree/main) and use Code -> Download ZIP.

To download this experimental source, stay on this branch and use Code -> Download ZIP. Read [COMFYUI_ROCM_BUILD_GUIDE.md](COMFYUI_ROCM_BUILD_GUIDE.md) and [AMD_PORT.md](AMD_PORT.md) before building. GPU detection and an architecture override are available in the native builders; support on other GPUs has not been validated. Bake Forger has no custom native backend to rebuild.

Do not install this alongside the tested copy in custom_nodes. Preserve your existing ROCm Python and Torch environment.
