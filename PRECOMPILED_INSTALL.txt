Precompiled Windows AMD release

Target: gfx1201, tested on RX 9070 XT. Python 3.12, exact Torch
2.15.0a0+rocm10.2.0a20260926, HIP 7.17.26384, SDK 10.2.
Use the existing compatible ComfyUI ROCm interpreter. No automatic GPU rebuild.
Other GPUs and Torch/SDK versions are not validated. Python, Torch, ROCm,
Microsoft VC++ runtime, model weights and Blender are not bundled.

Close ComfyUI, extract the node folder under custom_nodes, and move older copies
outside custom_nodes to avoid duplicate registration. The source build instructions
remain in README/AMD_PORT.md; for this bundle follow these precompiled steps.
In the commands below, python means your ComfyUI python_env/python.exe.
Run commands from the extracted node folder. Install missing small dependencies
from requirements files separately without replacing Torch.

Diagnostic source/PDB paths were anonymized in release copies using same-length
replacements in non-executable read-only data. Executable sections, import/export
interfaces and file sizes were preserved. Original installed binaries are intact.
Original production validation applies to the original builds. Release copies
are checked with small native smoke tests, not repeated production benchmarks.

This node needs no native extension compilation. Install Blender 5.2 separately,
ensure the listed Python dependencies exist, select HIP, and restart ComfyUI.
Its tested scope is the six-map 64x64 one-sample bake described in AMD_PORT.md.
